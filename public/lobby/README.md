# Lobby Custom Assets

Drop your cartoon images in this folder with these exact filenames:

## Mode cards (in `cards/` subfolder)
- `cards/imitation.png` — purple microphone mascot card
- `cards/audiophone.png` — orange/yellow speaker card
- `cards/2v2.png` — blue "2 vs 2" numbers card
- `cards/quiz.png` — green magnifying glass + ? card
- `cards/blindtest.png` — cyan headphones card
- `cards/memory.png` — pink padlock + key card
- `cards/undercover.png` — purple detective card

## Other
- `pret-stamp.png` — yellow "PRÊT !" starburst with peace fingers
- `mascot.png` — purple spiky-haired mascot with sunglasses
- `logo.png` — "C2TV MUSIC MASTER" graffiti logo
- `quitter-icon.png` — small QUITTER icon (optional)

If a file is missing, the code falls back to a stylized SVG/emoji rendering.
